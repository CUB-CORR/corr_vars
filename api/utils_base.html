Offsets#

corr_vars.utils.base.normalize_offset(offset)[source]#

Coerce an offset to the polars duration language.

A polars-duration string ("28d", "6h") is returned unchanged; a timedelta is rendered in microseconds. This is the single place that turns an OffsetLike into the string dt.offset_by needs — which does not accept a timedelta.

Parameters:

offset (str | timedelta)

Return type:

str
